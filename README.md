# CORSOLID — Civil 3D 코리더 솔리드 일괄 추출

도면에 있는 여러 코리더의 솔리드를 한 번에 추출하는 Civil 3D 플러그인입니다.
Civil 3D의 '코리더에서 솔리드 추출'을 코리더마다 반복한 것과 같은 결과가 나옵니다.

- 코리더 목록 창에서 검색하고 체크해서 고른다 (도면에서 클릭으로 고르기도 가능)
- 출력 객체 유형: 3D 솔리드(단면 기반) / 3D 솔리드(스윕 기반) / 바디
- 출력 대상: 현재 도면 / 기존 도면 / 새 도면
- 최신이 아닌 코리더는 다시 만든 뒤 추출
- (선택) 추출 전 모든 영역의 시작 측점 +0.01 m, 끝 측점 −0.01 m
- 레이어 `SOLIDS - 코리더이름 - 코드이름`, 코리더 특성세트(코리더 ID / 모형 정보 / 쉐이프 정보)는 Civil 3D가 자동으로 붙임

**지원 버전:** Civil 3D 2026 (Windows 64비트). 2025 이하는 동작하지 않습니다.

## 설치

1. 오른쪽 **Releases**에서 최신 `CorridorSolids_vX.X.zip`을 받아 압축을 풉니다.
2. Civil 3D를 모두 끕니다.
3. `설치.bat`을 더블클릭합니다.
4. Civil 3D를 켭니다. 보안 경고가 나오면 **[항상 로드]**를 누릅니다.
5. 명령행에 `CORLIST`를 입력해서 코리더 목록이 나오면 설치된 것입니다.

새 버전으로 바꿀 때도 Civil 3D를 끄고 새 `설치.bat`을 다시 실행하면 됩니다. 제거는 `제거.bat`입니다.

## 명령

| 명령 | 하는 일 |
|---|---|
| `CORSOLID` | 코리더 목록 창에서 골라서 추출 |
| `-CORSOLID` | 같은 기능을 명령행으로 (현재 도면에만) |
| `CORLIST` | 도면의 코리더 목록과 최신 상태를 명령행에 표시 |
| `CORSOLIDUPDATE` | 새 버전이 있는지 지금 바로 확인 |

자세한 사용법은 [사용법.txt](사용법.txt)를 보세요.

## 자동 업데이트 (v1.4부터)

Civil 3D를 켜면 하루 한 번 이 저장소의 최신 Release를 확인합니다. 새 버전이 있으면 물어본 뒤 받아 두고,
**Civil 3D를 모두 끄면 자동으로 설치**됩니다(켜져 있는 동안은 dll이 잠겨 있어서). 다음에 켤 때부터 새 버전이 적용됩니다.
v1.3 이하를 쓰고 있다면 v1.4를 한 번 직접 설치해야 합니다.

**새 버전을 낼 때(관리자):** Release 태그는 `v1.5`처럼, 첨부 파일은 `.zip` 하나(안에 `CorridorSolids.bundle` 포함),
zip 안 dll 버전이 태그와 같아야 합니다. Release 설명란 내용이 업데이트 알림 창에 표시됩니다.

## 빌드

Civil 3D 2026이 설치된 PC에서:

```
dotnet build src\CorridorSolids.csproj -c Release
```

나온 `CorridorSolids.dll`을 `CorridorSolids.bundle\Contents`에 복사합니다.
AutoCAD 설치 경로가 다르면 `src\CorridorSolids.csproj`의 `AcadDir`을 고칩니다.
