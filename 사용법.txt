코리더 솔리드 일괄 추출 (CORSOLID)  v1.4
==========================================

도면에 있는 여러 코리더의 솔리드를 한 번에 추출한다.
Civil 3D의 '코리더에서 솔리드 추출'을 코리더마다 반복하는 것과 같은 결과가 나온다.
  - 레이어: SOLIDS - 코리더이름 - 코드이름
  - 특성세트: 코리더 ID / 코리더 모형 정보 / 코리더 쉐이프 정보 (Civil 3D가 자동으로 붙임)
  - 현재 도면 / 기존 도면 / 새 도면 중 골라서 넣을 수 있다.

지원 버전: Civil 3D 2026 (AutoCAD 2026 기반)
  ※ 2025 이하 버전에서는 동작하지 않는다(따로 빌드해야 함).


1. 설치
-------
  1) Civil 3D를 모두 끈다.
  2) CorridorSolids_Setup_v○.○.exe 를 실행하고 [설치]를 누른다.
     ('Windows의 PC 보호' 창이 뜨면 [추가 정보] → [실행]. 서명하지 않은 프로그램이라 처음에 나오는 경고다)
  3) Civil 3D를 켠다. 처음 켤 때 보안 경고(실행 파일 로드)가 나오면 [항상 로드]를 누른다.
  4) 명령행에 CORSOLID 를 입력해서 코리더 목록 창이 뜨면 설치된 것이다.

  설치 위치: %APPDATA%\Autodesk\ApplicationPlugins\CorridorSolids.bundle
  제거: 같은 Setup.exe를 실행해서 [제거] (Civil 3D를 끈 상태에서)
  exe를 실행할 수 없는 PC: zip을 받아 압축을 풀고 '설치.bat' / '제거.bat'을 쓴다(같은 결과).
  새 버전: v1.4부터는 자동으로 알려 준다(6. 자동 업데이트). 직접 바꿀 때는 새 Setup.exe를 실행한다.


2. 명령
-------
  CORSOLID   코리더 목록 창에서 골라서 추출 (기본 사용법)
  -CORSOLID  같은 기능을 명령행으로 (창 없이)
  CORLIST    도면의 코리더 목록과 최신 상태를 명령행에 보여 준다.
  CORSOLIDUPDATE  새 버전이 있는지 지금 바로 확인한다. (6. 자동 업데이트)


3. CORSOLID 창 사용법
---------------------
  [검색]  이름 일부만 써도 목록이 걸러진다.
          예) 유지보수도로        → 유지보수도로#1 ~ #42
          예) 유지보수도로#1?     → 유지보수도로#10 ~ #19   (? = 한 글자, * = 여러 글자)
          예) 길내기, 정거장      → 둘 중 하나라도 들어간 코리더
          ※ 검색으로 목록에서 숨겨져도 체크한 것은 그대로 유지된다.

  [목록]  추출할 코리더를 체크한다.
          상태가 '최신 아님'(주황색)인 코리더는 다시 만들기(Rebuild)가 필요한 것
          (프로스펙터의 노란 ! 표시).

  [전체 선택] / [선택 해제]   지금 목록에 보이는 코리더만 한꺼번에 체크/해제
  [도면에서 선택...]          창이 잠시 닫히고, 도면에서 코리더를 클릭/걸침 선택 → Enter
                              → 고른 코리더가 체크된 상태로 창이 다시 열린다.

  [추출 설정]
    - 최신이 아닌 코리더는 다시 만든 뒤 추출 (기본: 켬)
        켬: 다시 만든 다음 추출 → 현재 기준선/서피스가 반영된 형상
        끔: 지금 코리더 형상 그대로 추출
        코리더가 크면 다시 만들기에 시간이 걸릴 수 있다.
    - 출력 객체 유형 (Civil 3D 추출 창과 같은 세 가지)
        AutoCAD 3D 솔리드 (코리더 단면 기반)   ← 기본
        AutoCAD 3D 솔리드 (스윕 기반)
        AutoCAD 바디
    - 추출할 것: 쉐이프 (기본: 켬) / 링크 (기본: 끔)
    - 제외할 코드: 쉼표로 구분 (비워 두면 전부)
    - 추출 전 모든 영역의 시작 측점 +, 끝 측점 − [0.010] m (기본: 끔)
        고른 코리더의 모든 기준선, 모든 영역(RG)에서 시작 측점을 +값, 끝 측점을 −값 바꾼 뒤
        코리더를 다시 만들고 추출한다. (영역끼리 맞닿는 곳의 솔리드가 겹치지 않게 할 때)
        - 코리더의 영역 측점이 실제로 바뀐다. 현재 도면이면 U로 되돌릴 수 있다.
          (기존/새 도면으로 추출해도 코리더 변경은 지금 도면에 남는다 → U로 되돌리기)
        - 실행할 때마다 다시 그만큼 줄어든다. 한 번 한 코리더에 또 켜고 돌리지 않도록 주의.
        - 길이가 (값×2) 이하인 짧은 영역은 건너뛴다.
        - 추출을 누르면 한 번 더 확인 창이 뜬다.

  [출력 대상]
    - 현재 도면에 삽입 (기본)
        끝나면 새로 만든 솔리드가 모두 선택된 상태가 된다.
        → 바로 이동/복사/WBLOCK 가능. 결과가 이상하면 U 한 번으로 이번 추출 전체를 되돌린다.
    - 기존 도면에 추가
        [...]로 도면을 고른다. 그 도면을 화면에 열지 않고 뒤에서 솔리드를 넣고 저장한다.
        추출 전 도면은 같은 폴더에 .bak 파일로 남는다(되돌릴 때 .bak을 .dwg로 이름 바꾸기).
        ※ 그 도면이 AutoCAD에 열려 있거나 다른 사람이 열고 있으면 실패하니 먼저 닫는다.
    - 새 도면에 추가
        기본 이름은 '지금도면이름_솔리드.dwg'. [...]로 위치/이름을 바꿀 수 있다.
        같은 이름의 파일이 있으면 덮어쓸지 묻는다. 단위(INSUNITS)는 지금 도면을 따른다.
    ※ Civil 3D 추출 창의 '코리더에 대한 동적 링크'는 지원하지 않는다(Civil 3D가 프로그램용으로 열어 두지 않은 기능).

  [추출]  창이 닫히고 추출이 진행된다. 코리더마다 솔리드 개수가 명령행에 표시된다.
    - Esc를 누르면 지금 코리더까지만 하고 멈춘다(만든 것은 남는다. 기존/새 도면이면 거기까지 저장).
    - 실패한 코리더는 건너뛰고 끝에 목록으로 보여 준다.

  Civil 3D를 끄기 전까지는 마지막 선택/검색어/설정을 기억해서 다음에 창을 열 때 그대로 보여 준다.


4. -CORSOLID (명령행 버전)
--------------------------
  (1) 대상 [전체(A) / 이름으로(N) / 화면에서(P)]  <Enter = 전체>
      이름으로: 위 검색과 같은 규칙. 단, 이름이 정확히 같은 코리더가 있으면 그것만 고른다.
                (예: 유지보수도로#1 → #1만. #10~#19는 포함하지 않음)
  (2) 최신이 아닌 코리더가 있으면: 다시 만든 뒤 추출할까요? <Enter = 예>
  (3) 추출 설정: T 출력 객체 유형(누를 때마다 바뀜) / S 쉐이프 / L 링크 / E 제외 코드, Enter = 추출 시작
      명령행 버전은 '현재 도면에 삽입'만 된다. 다른 도면으로 보내려면 CORSOLID 창을 쓴다.


5. 참고
-------
  - 같은 코리더를 두 번 추출하면 솔리드가 두 벌 생긴다. 다시 추출할 때는 이전 솔리드를 지운다.
  - 코리더 도면이 크면 추출한 솔리드를 WBLOCK으로 따로 저장해 쓰는 것이 가볍다.
  - 소스: src\ (CorridorSolids.cs, CorridorDialog.cs, CorridorForm.cs, Common.cs, UpdateCore.cs, UpdatePlugin.cs)
    빌드: dotnet build src\CorridorSolids.csproj -c Release
          → 나온 CorridorSolids.dll 을 CorridorSolids.bundle\Contents 에 복사
    설치 프로그램: dotnet publish setup\CorridorSolidsSetup.csproj -c Release -o <출력폴더>
          → CorridorSolids_Setup.exe (번들이 exe 안에 들어감. 위에서 dll을 먼저 복사한 뒤 만든다)
          아이콘: setup\corsolid.ico (setup\make_icon.ps1로 다시 그릴 수 있음)


6. 자동 업데이트 (v1.4부터)
---------------------------
  Civil 3D를 켜면 하루에 한 번 GitHub(https://github.com/ryunhyun/civil3d-corsolid)에서
  새 버전이 있는지 확인한다. 확인은 뒤에서 하므로 Civil 3D가 켜지는 속도에는 영향이 없다.

  새 버전이 있으면 '새 버전이 있습니다' 창이 뜬다.
    [예]     새 버전을 받아 둔다. Civil 3D를 모두 끄면 자동으로 설치되고, 다음에 켤 때부터 적용된다.
             (Civil 3D가 켜져 있는 동안에는 파일이 잠겨 있어서 바꿀 수 없기 때문)
             다음에 켜면 명령행에 '○○(으)로 업데이트되었습니다'가 나온다.
    [아니요] 지금은 받지 않는다. 내일 다시 알려 준다.

  CORSOLIDUPDATE   하루 한 번을 기다리지 않고 지금 바로 확인한다.

  - 인터넷이 안 되거나 GitHub에 접속할 수 없으면 아무것도 묻지 않고 넘어간다.
    그럴 때는 https://github.com/ryunhyun/civil3d-corsolid/releases/latest 에서 zip을 받아 '설치.bat'을 실행한다.
  - 기록: %LOCALAPPDATA%\CorridorSolids\update.log
  - v1.3 이하에는 자동 업데이트가 없다. v1.4는 한 번 직접 설치해야 하고, 그다음부터 자동으로 된다.
